# MEF LSO Sonata MCP Server Simulator

An open-source Model Context Protocol (MCP) server implementation simulating MEF LSO Sonata APIs (Address Validation & Quote Management) for AI Agent integration.

## Features

- **Address Validation Tool**: Simulates MEF 121 / MEF 79 `FieldedAddress` validation.
- **Quote Management Tool**: Simulates MEF 115 / MEF 80 `Quote_Create` workflows for `UNI` and `ACCESS_E_LINE` network products.
